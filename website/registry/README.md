# registry/

`scenes.json` is generated by `npm run manifest` (`scripts/merge-manifest.mjs`)
from `docs-out/docs-manifest.json` plus the scene ids registered in
`docs-showcase/SceneRegistry.kt`. It is checked in so pages
(`SceneIndex.astro`) and `npm run check:registry` can read it without running
the capture job first; regenerate it whenever `docs-out/` changes.

## Release snapshot

`releases.json` is generated by `npm run releases:sync`
(`scripts/sync-releases.mjs`) from the GitHub Releases API. It freezes the
normalized stable and nightly release metadata the download page
(`VariantPicker.astro`) renders before any JavaScript runs, so the site has no
runtime network dependency for the default download link. Re-run the command
to refresh the snapshot; the picker still checks for newer releases live in
the browser.
