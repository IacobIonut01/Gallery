Ignoring removes albums from view without deleting or encrypting anything. Each entry under **Library › Ignored** is a rule with two decisions: **where** it hides media (the Timeline, the Albums tab, or both) and **who** it matches (a single album, several albums, or a path pattern). Rules are reversible; deleting one brings everything back.

## Create a rule

1. Open **Library › Ignored** and start a new rule. The same wizard opens when you touch and hold an album and choose **Add to ignored albums**.
2. Under **Where should be ignored**, pick **Timeline**, **Albums**, or **Both Albums and Timeline**. A Timeline-only rule still leaves the album visible on the Albums tab.
3. Under **Who should be ignored**, pick **Single Album**, **Multiple Albums**, or **Path Regex**.
4. For album selections, tick the albums in the list; selected albums show as chips with a running count, and **Continue** moves on.
5. For **Path Regex**, type the pattern (see below) and check the **albums matched** preview before continuing.
6. The **Confirmation** step previews the type, the location, and the matched albums. Tap **Apply** to save the rule.

## Path patterns

A path pattern is matched against the **entire path** of each file and its folder, not the album's display name. For example a file lives at `/storage/emulated/0/DCIM/Camera/photo.jpg`, so a pattern must cover that whole string. Use `.*` where anything may appear.

The app suggests these examples:

| Pattern | Matches |
| --- | --- |
| `.*Screenshots.*` | Anything with "Screenshots" in its path |
| `.*/WhatsApp/.*` | Everything inside a WhatsApp folder |
| `/storage/emulated/0/DCIM/.*` | Everything under DCIM on internal storage |

Two mistakes produce errors: an **Invalid pattern** that does not parse, and a pattern **already in use** by another rule. Always check the matched-albums preview before applying; a pattern that matches more than intended hides more than intended.

## Manage existing rules

1. Open **Library › Ignored**.
2. Tap a rule's options to **Edit Albums** (change which albums it covers), **Edit Location** (Timeline vs Albums scope), or **Delete** it.
3. Save or cancel with **Save** / **Cancel**.

Deleting a rule makes its albums visible again where it had hidden them; nothing about the files changes in either direction.

## Example: hide messaging clutter only from the Timeline

1. Open **Library › Ignored** and start a rule.
2. Choose **Timeline** for the location so the folders still exist on the Albums tab.
3. Choose **Path Regex**, enter `.*/WhatsApp/.*`, and check the matched preview shows the media folders you expect.
4. Tap **Continue**, review the confirmation, and **Apply**. WhatsApp media leaves the Timeline but the files and the album remain.

## If the wrong things disappear

- Open **Library › Ignored** and check the matched albums on the rule; path patterns match more than one folder when they are broad.
- A rule scoped to **Timeline** is the reason an album still shows on the Albums tab; that is by design, not a leak.
- Ignored media may still feed search and smart features if **Include ignored albums** is on under **Settings › Smart Features**.
