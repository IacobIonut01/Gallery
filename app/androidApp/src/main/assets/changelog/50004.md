## What's new in 5.0.0

The biggest release yet — cloud sync with Immich, backup & restore, new editor effects and a faster viewer pipeline.

### New features
- **Cloud sync & Immich** — Connect your self-hosted Immich server and browse remote photos in a unified timeline with people, map, and smart search.
- **Cloud photo backup** — Back up selected albums to your server with deduplication and Wi-Fi/cellular controls.
- **Backup & restore wizard** — Export and import settings, favorites, cloud configs, and vaults, with optional password encryption.
- **New editor effects & filters** — Posterize, Edges, Borders, Hue, black & white, and a one-tap Negative preset.
- **Flexible date grouping** — Group media by day, month, or year — configurable per screen.
- **Album sections** — Organize albums into collapsible Common, Apps, and Other sections.
- **Save motion photo as video** — Export the embedded clip from a motion photo as a standalone MP4.
- **Advanced Protection support** — Automatically hardens decoding and metadata isolation when Android Advanced Protection is on.
- **Location detail sheet** — Tap a photo's location to see a map preview with quick actions to open it in app or externally.

### Improvements
- **Better APNG & JXL** — Improved animated APNG playback and JPEG XL image support.
- **Performance & smoother scrolling** — Faster grid rendering, image loading paused while fast-scrolling, prefetching for flicker-free transitions, and a new Sketch-based viewer pipeline.

### Bug fixes
- Fixed panorama mirroring, background audio on focus loss, picker album thumbnails, file descriptor leaks, vault UX issues, duplicate-key crashes, and SD card copy/move destinations.
