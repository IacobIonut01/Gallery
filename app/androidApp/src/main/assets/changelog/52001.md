## What's new in 5.2.0
ReFra 5.2.0 rebuilds People on accurate batch face clustering, turns cloud backup into real two-way sync, and adds NFS shares, server-side smart search, custom upload folders, capture-time ordering and verified cloud-to-cloud transfers.

### New features
- **Rebuilt People section** — deterministic batch clustering with merge review, possible duplicates, hidden people and a detected-faces strip. Remove wrongly assigned faces from a person — in the grid or from the viewer — without deleting photos.
- **Two-way cloud sync** — download remote-only media per account, propagate remote deletions, and reconcile Immich libraries with delta-sync plus a periodic full sweep.
- **NFS support** — mount NFS shares as LAN cloud providers alongside SMB.
- **Server-side smart search** — text and visual search delegate to capable providers like Immich, synced server tags join metadata search, and Cloud libraries settings control indexing per provider.
- **Custom upload folders** — per-account upload and video base paths plus per-album overrides for WebDAV, ownCloud, Nextcloud, SMB and NFS.
- **Capture-time ordering** — embedded photo and video dates drive the timeline so copied or moved files stop jumping; fix a capture date from the viewer.
- **Copy and Move to cloud albums** — verified transfers between device and cloud albums, including across providers, with progress previews.
- **Fluid viewer transitions** — the media viewer opens and closes with a shared-item animation and drag-to-dismiss peeks at the previous screen.

### Improvements
- **Instant feedback** — trash, delete, restore and favorite apply to the grid immediately, and the viewer keeps browsing after a delete.
- **Faster startup** — cached Library and startup snapshots draw content on the first frame; album state and scroll position survive deep opens.
- **Lighter backup** — fewer foreground writes and throttled progress keep the app responsive while uploads run.
- **Selection action bar** — long action lists scroll instead of squashing labels, with a new Fill action bar option.

### Bug fixes
- Ignored cloud albums now hide their media from the unified timeline.
- Restored blurred video chrome and stable Story Cards viewer dismissal.
- Cloud thumbnails await account init, NetFS videos get posters, and remote deletion is idempotent.
- Splash screen icon follows the selected launcher logo.
- Saved location names repair automatically at startup.
- Static map previews keep square tiles on wide cards.
