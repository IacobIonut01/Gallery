## What's new in 5.1.2
ReFra 5.1.2 protects originals more carefully, verifies remote backups more thoroughly, and improves reliability across large local, NAS, JPEG XL, video, and location libraries.

### Improvements
- **Reliable native codec packaging** — Clean and F-Droid builds now reproducibly include the full native image codecs instead of fallback stubs.

### Bug fixes
- **Trustworthy cloud backups** — WebDAV, SMB, and NFS copies are verified by streamed content hashes before they count as safe backups.
- **Reliable large NAS libraries** — Large SMB and NFS shares now provide stable paging, albums, thumbnails, and media streaming from a complete reusable index.
- **Lossless metadata removal** — ReFra fully verifies a sanitized copy before the original can be moved to system trash.
- **Safer editor overwrites** — Originals stay visible during replacement and can be restored after a partial write failure.
- **JPEG XL metadata** — Exif and XMP now load from direct and Brotli-compressed JPEG XL metadata boxes.
- Existing local and SD-card folders are selectable as album move destinations again.
- Large albums retain deep grid and viewer positions after restoration.
- Location cards open the correct timeline and media without duplicate location identities.
- Videos opened from other apps no longer flash viewer controls over the first frame.
