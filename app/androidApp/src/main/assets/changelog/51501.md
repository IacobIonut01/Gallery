## What's new in 5.1.5
ReFra 5.1.5 is a focused reliability update that improves photo location accuracy, slideshow startup, and offline launches.

### Bug fixes
- **More accurate photo locations** — ReFra now repairs every unresolved location batch, groups coordinate-only locations consistently, and centers static maps on the photo's exact GPS position.
- **Reliable slideshow startup** — Slideshows now wait for media loading to finish before deciding whether the selection is empty.
- **Crash-free offline startup** — Offline builds no longer query unavailable network state during startup.
