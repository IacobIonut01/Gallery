## What's new in 4.2.2

A security-focused release: app sandboxing, encrypted storage and a private folder.

### New features
- **Security hardening** — App sandbox (targetSandboxVersion 2), encrypted storage, and isolated file processing.
- **Sandboxed image decoding** — HEIF, AVIF, and JXL images are decoded in isolated processes for exploit protection.
- **Isolated metadata parsing** — EXIF and metadata extraction runs in per-file sandbox processes.
- **Private folder** — Store sensitive files outside MediaStore via SAF, hidden behind a security gate.
- **Encrypted storage** — Encrypt app preferences (AES-256-GCM) and Room database (SQLCipher) at rest.

### Improvements
- **Persistent rescan tracking** — MediaStore rescan state is now persisted in the database across app restarts.
- **Various performance improvements** — Lazy per-album timeline flows, reduced recompositions in media viewer, optimized collection types and state management.

### Bug fixes
- Fixed slow AI classification, dark status bar icons, map intent crash, motion player leak, large batch copy crash, filename date fallback, and updated dependencies.
