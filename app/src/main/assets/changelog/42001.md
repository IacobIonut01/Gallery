## What's new in 4.2.0

Album organization, image-to-image search, a mosaic layout and a full settings redesign.

### New features
- **Album groups** — Organize albums into collapsible groups.
- **Merge albums by name** — Automatically combine albums that share the same name.
- **Merge sub-folder albums** — Consolidate nested sub-folder albums into their parent.
- **Frame-accurate video seeking** — Precise video scrubbing with adjustable sensitivity.
- **Image-to-image search** — Find visually similar photos using any image as a query.
- **Mosaic grid view** — Dynamic mosaic tile layout for the timeline.
- **Collections** — Create custom albums by grouping photos from anywhere.
- **Configurable selection sheet** — Customize which actions appear and their order.
- **Granular grouping settings** — Fine-tune which similar photos are grouped together.
- **Optional AI models** — AI models can now be downloaded on demand instead of bundled.

### Improvements
- **Settings redesign** — Complete UI and UX overhaul for all settings screens.
- **Refreshed button style** — New unified button design used throughout the app.
- **Categories UI refresh** — Redesigned categories screen with improved navigation.

### Bug fixes
- Fixed video codec exhaustion, favorite button in timeline, and grouped media selection.
